# Inner Flare 1.5.0: release notes

Everything that's landed since
[v1.4.0](https://github.com/Health-Flare/InnerFlare/releases/tag/v1.4.0):
a full rebrand to Health Flare's new visual identity.

A new colour palette, app icon and typography, no schema change, nothing
removed, no behaviour change. Older backups still import. This is a minor
version (`1.5.0`), build number `8`.

## Full release notes

### A new look

Inner Flare now matches Health Flare's updated visual identity:

- A warmer, rose-based colour palette in place of the old orange and teal.
- A new app icon, including dark-appearance and Android themed-icon
  variants.
- Fraunces and DM Sans as the new display and interface typefaces.

Nothing about logging, predictions, backups, or the lock screen has
changed. This is a look-and-feel update only.

### Under the hood

Dependency maintenance: `flutter_local_notifications` updated to v23,
routine lock file refresh, a pinned GitHub Actions digest bump. No
user-visible change.

## Cutting this release

See `docs/deployment/release-process.md` for the full, ordered process;
this list is the 1.5.0-specific part.

- [x] Decide the version number: a visual rebrand only, no schema change,
      nothing removed, so a minor bump, `1.5.0`.
- [x] Bump `version:` in `pubspec.yaml` to `1.5.0+8` (Android
      `versionCode` 8, iOS build 8; build 7 is the last upload).
- [x] Release notes and store "What's new" copy written (this file).
- [x] F-Droid draft metadata points at `v1.5.0` / versionCode `8`.
- [x] Store screenshots and the App Store creative videos were already
      regenerated against the rebranded app (see the brand v2.0 PR);
      confirmed current, no re-shoot needed for this release.
- [ ] Upgrade test on a real device: no schema change this release, so
      this is a lighter check than usual, but still confirm data,
      dashboard layout and unlock all survive installing 1.5.0 over a
      1.4.0 install, and that a 1.4.0 backup still imports.
- [ ] Release-mode check: no debug-only UI (database status icon,
      Settings' Database and Demo data sections).
- [ ] Merge to `main`, then tag `main` with `v1.5.0` and push the tag.
- [ ] Play: install from internal testing, paste "What's new", promote to
      production.
- [ ] App Store: confirm the new icon and screenshots appear correctly on
      the product page before submitting for review.
