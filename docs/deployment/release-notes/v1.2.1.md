> **Inner Flare 1.2.1**
>
> Fixes an error that appeared when you dragged a card to reorder it in
> Customize dashboard. Reordering now works smoothly.

---

## Full release notes

### Fixed: dragging a card in Customize dashboard showed an error

Picking up a card by its handle to reorder it in Customize dashboard
raised a red "No Material widget found" error, because the card being
dragged was lifted out of the screen it normally sits in. Each row now
carries its own drawing surface, so the drag works without an error.
